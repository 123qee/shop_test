# Joom 平台规则与优化依据

核查日期：2026-11-26（北京时间）。适用方向：中国卖家、成人及儿童印花服装、Joom 广告和店铺经营。

本资料来自 [Joom 中国卖家帮助中心](https://merchant.joom.com/help-center/china/)的 **36 篇正文**及 **3 份正式政策/条款的相关章节**。通过浏览器读取新版中文正文；旧入口 `merchant-help.joom.com/hc` 本次无法访问，新版是动态页面，普通网页抓取只能得到空壳。这里只保存归纳、来源和项目应用方法，不复制培训中心全文。

## 先记住的变化与边界

1. 当前名称专页上限为 **150 字符**；不沿用第三方旧教程的100字符限制。[S02]
2. 名称、描述、属性冲突时，系统可能按描述更新名称。先修真实描述，再统一所有字段。[S02] [S03]
3. 服装尺码写入描述，让平台生成表。商品相册不能拿尺码表图片代替结构化尺码。[S06] [S07] [S08]
4. 普通商品图、按语言上传的详情图是不同模块，语言和logo规则不同。[S04] [S11]
5. 不能把“服装一律不能定制”当成当前全部规则。POD专页提供独立店铺和申请权限的路径；现有三店是否获批，本次未查。[S07] [S13]
6. 官方健康指标有各自的滞后考核窗口，56天经营退款率不能直接映射店铺等级。[S27] [S28] [S29]
7. 广告归因销售额、配置预算、实际实收和利润是不同指标。项目成本和权限仍读取 [经营规则](../../经营规则.json)。[S18] [S20]

## 如何解释本知识库

- **官方要求/官方建议**：带 S 编号，可点击回到具体原文。平台推荐提高出价、降低价格或测试新品，不等于对我们有利润保证。
- **项目应用/检查方法**：本次结合现有资料提出的操作方法，不是Joom公布的算法或处罚标准。
- **待核实**：制造商、授权、真实面料比例、实测尺寸、账户权限和实时限制等，没有证据时不填成已满足。

规则适用范围由商家主体、目的国、商品类目、功能权限和实际适用协议共同决定。中国卖家页面和正式条款为主要依据；站点所在地不等于卖家主体所在地。涉及证书的内容记录平台要求，不将其泛化为所有国家的法律结论。

## 冲突与缺口登记

| 项目 | 本次发现 | 后续采用方式 |
| --- | --- | --- |
| 服装普通页面与POD | 普通服装页禁止私下定制；POD专页允许获批专店通过平台模块定制 | 区分普通商品与获批定制，申请前核实支持团队要求 |
| 图片格式 | 字段总览包含GIF，图片专页只列PNG/JPG/JPEG | 本项目优先使用PNG/JPG/JPEG，同时满足尺寸要求 |
| 商品类目 | 审核页说卖家不能决定类目；新字段页提供建议类目 | 卖家提交建议，平台决定最终类目；错误分类须复核/申请纠正 |
| 材质比例 | 通用材质页可写已知材质；欧盟服装页要求纤维百分比 | 欧盟按特定要求补真实比例，不猜填100% |
| 履约时限 | 帮助页区分48小时交物流和7天上网；中国条款§6.11另载4工作日发货 | 不合并为一个时限；逐订单核对倒计时、承诺及适用条款 |
| 旧“产品变型要求”链接 | `667711250a35380881b436b9` 本次显示404 | 使用已读的新版字段页、童装页与处罚页；不假称读到了旧页 |
| 日期 | 中文帮助正文未显示发布/更新日 | JSON留null；核查日不当作政策生效日 |

本次未遍历全部帮助中心，未观看直播/付费课程，未读取所有物流线路、FBJ、税费和类目法规，也未重新检查后台业务设置。具体处罚、证书适用、价格限制和GTIN例外需在行动前核实，不据摘要自动执行。

## 更新办法（项目约定）

提出Joom优化时先读本目录和最新项目记录，引用规则编号与证据。遇到新诊断、政策变更、来源失效或文本冲突时立即复核。距上次核查超过30天时，在依赖动态规则作具体修改前重新打开相关官方原文；30天是本项目复核约定，不是平台时限。

更新时记录原/新规则、适用范围、核查日期和受影响建议；保留旧记录，不改写历史日报。按需留下日期版变更说明。这里只补充阅读入口，未更改定时任务、经营成本或业务操作权限。
