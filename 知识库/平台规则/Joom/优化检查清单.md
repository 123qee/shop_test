# Joom 下一次优化检查清单

制定日期：2026-11-26。这里是项目操作方法，引用官方规则作依据；不代表已经执行任何后台修改。

## 按问题选择动作

| 现象 | 先核实什么 | 满足条件后的优化方向 | 依据 |
| --- | --- | --- | --- |
| 无曝光或限售 | 商品/在售版本、目的国、平台诊断、证件和授权 | 修正真实缺口或正规复核，再考虑广告 | [S12] [S16] [S21] |
| 有曝光但CTR低 | 主图是否清楚，产品类型/图案/人群是否匹配，前台价格运费 | 测试真实主图或更准确名称，保留对照 | [S02] [S04] |
| 有点击/加购但少成交 | 实物与文案、规格、尺码、套装构成、到手总价、时效 | 优先消除购买疑问；按实测补尺码、补真实详情图 | [S03] [S06] [S11] |
| 已有成交但内容缺失 | 视频/详情图、精选状态 | 在权限范围内补内容，核实在售生效 | [S25] [S26] |
| CPA或CPM成本偏高 | 策略和单位、逐商品花费、归因、实收和售后 | 给具体控费方案，按同口径跟踪 | [S18] [S19] [S20] [S22] |
| 显示价格风险或拟降价 | 7天参考价、各尺码价格、地区折扣和成本 | 先核原因，满足价格规则再改 | [S15] [S23] [S24] |
| 退款或取消偏高 | 官方窗口、具体订单、错误根因和履约阶段 | 先修产品/出货问题，再评价投放扩量 | [S28] [S29] [S33] [S34] |

## 必须完成的提交前检查

- [ ] 标明店铺、产品ID、变型、目的国、当前在售版本和本轮目标。
- [ ] 引用适用官方S编号，并核查原文日期/范围；动态规则过期或有冲突时重新读取。
- [ ] 将已确认事实、待确认供应/材质/尺寸、分析假设分别写清。
- [ ] 名称、描述、属性、主图、类目建议与真实商品一致；英文名称≤150字符。[S02] [S03] [S10]
- [ ] 材质有依据，未知比例不猜填；欧盟标签与证件另核。[S05] [S09] [S16]
- [ ] 全部可售尺码有真实数据，围度与宽度不混用；套装各部件写清。[S06] [S08]
- [ ] 图案与照片有合法使用依据；不通过改词、遮标或重铺规避限制。[S14] [S39]
- [ ] 未把相同商品跨三店重复铺货，未把不同商品或整套/单件混作变型。[S01] [S15]
- [ ] 配置价、折扣、运费、税费和实收分开；预算与费用单位清楚。[S18] [S19] [S23]
- [ ] 保存修改前字段、建议后字段、权限依据、预期改善环节、风险与复查条件。

## 当前项目优先核查项

以下来自 [2026-11-26经营日报](../../日报/店铺经营/2026-11-26/103207.md)及 [广告日报](../../日报/广告/2026-11-26/103207.md)，是历史记录映射，不是本次重新登录后台验证的状态。

| 优先级 | 已有问题 | 本次新增的规则依据与下一步 |
| --- | --- | --- |
| P0 | 人物、球队等印花及已提示IP问题的商品 | 先核授权链和地域，不能把有销量视为授权。[S14] [S39] |
| P1 | `6aad547abaf5a401f56aeddf`用户确认短袖，但旧记录仍卫衣名称/类目，袖长数据待实测 | 先用真实短袖描述统一字段，再核建议/最终类目和每码袖长；不要沿用卫衣测量。[S02] [S03] [S06] [S10] |
| P1 | `6a842f66e32015012461bc44`已确认聚酯纤维，旧记录仍有cotton属性和100%描述 | 统一材质类型，追索比例证据；欧盟缺口单列。[S05] [S09] |
| P1 | 欧盟/IP区域限制、价格风险计数变化 | 逐款拆诊断和地区，核制造商、欧盟代表、标签、授权及7天价格；不合并重叠数量。[S15] [S16] [S23] |
| P1 | 三店官方健康窗口和履约仍有缺口 | 补官方指标详情，不拿56天退款率判处罚等级。[S27] [S28] [S29] |
| P2 | 新广告拆分组仅少量首次成交，个别行0点击却有归因购买 | 等待同步和归因，核逐单利润与合规后再放量；不能据单笔低ACOS外推。[S20] [S22] |
| P2 | 有成交商品、精选候选或内容缺失商品 | 核实内容状态和权限，补真实视频/详情图；接受精选价格前计算贡献利润。[S11] [S25] [S26] |
| P2 | 英德等主销地区、站外流量机会 | 优先检查逐国可售、标签和真实到手价，再核有效GTIN；不为流量编造品牌条码。[S16] [S36] [S37] |

P0/P1/P2是本项目本次建议优先级，不是平台处罚等级。整体扩量仍受现有“不加整体广告预算”的用户偏好及后续指令约束。

```text
建议编号：
店铺 / 产品 / 变型 / 国家：
数据统计窗口、平台时区、更新时间：
当前在售事实与证据路径：
引用官方规则：Sxx，标题，URL，核查日，适用范围
项目判断与待核实事实：
当前值 → 建议值（币种/单位/字段）：
预期改善：曝光 / 点击 / 转化 / 利润 / 售后 / 履约
权限依据与执行状态：
编辑保存时间 / 审核状态 / 真实在售生效时间：
复查窗口、同口径基线、继续/停止条件：
结果与混杂因素：价格、促销、库存、投放、地区、归因回补
```

按 [分析方法](../../分析方法.md)记录生效后观察。3/7/14天等是本项目观察安排，平台审核约96小时是官方通常时长，二者不要互相替代。没有执行证据，不从“建议”推进到“已执行”。
