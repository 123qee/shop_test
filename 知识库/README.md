## 每日积累

- `日报/广告/YYYY-MM-DD/HHmmss.md`：广告结论、调整建议和复查条件。
- `日报/店铺经营/YYYY-MM-DD/HHmmss.md`：各店铺、各站点的经营结论。
- `快照/广告/YYYY-MM-DD/HHmmss.json` 和 `快照/店铺经营/YYYY-MM-DD/HHmmss.json`：与报告配对的结构化指标及其实际统计日期。
- `调整记录/广告/` 和 `调整记录/店铺经营/`：按执行日期及时间保存建议、已确认动作和复查事件，记录之间通过稳定的建议编号关联。
- `复盘/`：有执行证据和后续观察后形成的经验。首次建议登记在[基线建议记录](调整记录/2026-11-17-基线建议.json)。

目前已保存的是历史基线，尚未产生新的定时运行日报。两个任务仍每天北京时间 11:00 运行，任务编号为 `joom` 和 `joom-2`。

## 保存约定

每条记录注明平台、店铺或国家、抓取时间、平台时区、指标窗口、来源、数据更新时间、完整性和计算假设。数值缺失用 `null` 并说明原因，不填零；金额注明币种，率在 JSON 中用 0—1 的小数。百分比展示时乘 100。

历史快照保留，同日重复运行使用不同时间文件名；归因回补写新版本并关联原快照，不覆盖旧观察。报告写入后读回并核对汇总，再在聊天中给出报告链接。采集失败也保存失败报告和缺失状态，不伪造指标。

这里只保存经营资料，不保存客户身份、地址、联系方式、账号密钥、Cookie 或访问令牌。数据库、商品模板及启动脚本继续沿用原有位置。
