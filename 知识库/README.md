## 保存约定

每条记录注明平台、店铺或国家、抓取时间、平台时区、指标窗口、来源、数据更新时间、完整性和计算假设。数值缺失用 `null` 并说明原因，不填零；金额注明币种，率在 JSON 中用 0—1 的小数。百分比展示时乘 100。

历史快照保留，同日重复运行使用不同时间文件名；归因回补写新版本并关联原快照，不覆盖旧观察。报告写入后读回并核对汇总，再在聊天中给出报告链接。采集失败也保存失败报告和缺失状态，不伪造指标。

这里只保存经营资料，不保存客户身份、地址、联系方式、账号密钥、Cookie 或访问令牌。数据库、商品模板及启动脚本继续沿用原有位置。
