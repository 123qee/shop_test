# shop_test

## 快速启动

### Windows

1. 在文件管理器中打开这个项目文件夹。
2. 双击 `启动工作台.bat`。
3. 启动脚本会按需安装依赖、构建网页；完成后会打开浏览器。首次安装需要联网，电脑需安装 Node.js 18 或更高版本。
4. 停止时回到启动窗口，按 `Ctrl + C`。

网页代码有修改、需要重新构建时，可以在命令提示符中运行 `启动工作台.bat --build-web`。

### macOS

1. 在 Finder 中打开这个项目文件夹。
2. 双击 `启动工作台.command`。
3. 启动脚本会按需安装依赖、构建网页；完成后会打开浏览器。首次安装需要联网，电脑需安装 Node.js 18 或更高版本。
4. 停止时回到启动窗口，按 `Control + C`，再按回车关闭窗口。

如果 macOS 首次拦截脚本，在 Finder 中右键 `启动工作台.command`，选择「打开」，并按提示确认。

## 原有终端启动方式

原有启动脚本仍可照常使用：

```bash
cd auto_tools
./start.sh
```

修改网页代码后如需重新构建：

```bash
cd auto_tools
./start.sh --build-web
```

更多配置和故障排查见 [auto_tools/README.md](auto_tools/README.md)。
