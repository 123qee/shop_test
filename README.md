## 快速启动

### Windows

1. 在文件管理器中打开这个项目文件夹。
2. 双击 `启动工作台.bat`。
3. 每次双击会先尝试拉取当前分支所跟踪的远程分支最新代码，最多等待 15 秒；未安装 Git、网络不通或拉取失败时，会提示并继续用本地代码启动。自动更新仅允许快进，不会自动合并冲突、暂存或丢弃本地改动。
4. 随后检查依赖和网页版本；源码、共享代码或配置变化时自动重新构建网页，再打开浏览器。电脑需安装 Node.js 22 或更高版本，项目推荐 Node.js 24（见 `.nvmrc`）。启动器会核对锁文件与已安装版本，实际加载 SQLite 等原生依赖，发现不兼容时按锁文件重新安装。
5. 停止时回到启动窗口，按 `Ctrl + C`。

在 **订单 → 订单导出** 可以同步订单并导出 Excel。默认地址是 [本机订单导出页](http://localhost:8787/orders)。如果旧版启动后看不到这个入口，先在旧启动窗口按 `Ctrl + C`，再在项目目录的 PowerShell 中运行 `.\启动工作台.bat --build-web`。

### macOS

1. 在 Finder 中打开这个项目文件夹。
2. 双击 `启动工作台.command`。
3. 启动脚本会检查依赖、按源码变化自动构建网页；完成后会打开浏览器。需安装 Node.js 22 或更高版本，推荐 Node.js 24；使用 nvm 且已安装 24 时会自动选用项目版本。首次启动新版启动器或依赖环境变化时会按锁文件安装，需要联网。
4. 停止时回到启动窗口，按 `Control + C`，再按回车关闭窗口。

如果 macOS 首次拦截脚本，在 Finder 中右键 `启动工作台.command`，选择「打开」，并按提示确认。

## 原有终端启动方式

原有启动脚本仍可照常使用：

```bash
cd auto_tools
./start.sh
```

修改网页代码后，正常启动即可自动重建；也可强制构建：

```bash
cd auto_tools
./start.sh --build-web
```

只检查环境、不安装依赖或启动服务：macOS 运行 `./auto_tools/start.sh --doctor`，Windows 运行 `.\启动工作台.bat --doctor`。仅准备依赖和网页、不启动服务时使用 `--prepare`。

更多配置和故障排查见 [auto_tools/README.md](auto_tools/README.md)。
