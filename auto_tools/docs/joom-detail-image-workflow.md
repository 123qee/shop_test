# Joom 缺失内容商品：英文详情图补齐流程

## 目标

为 Joom 后台显示“缺失内容”的商品补一张英文详情图，减少商品信息空缺。流程只新增详情图，不改变标题、主图、价格、库存、变体、SKU、类目或其他商品字段。

## 已验证样例

- 日期：2026-10-23
- 商品 ID：`6a84325c0fa41b0132656b6d`
- SKU：`TXYL0064`
- 结果：成功新增 1 张英语详情图；保存后商品详情页显示“详情图 / 英语”。
- 不变量：标题、2 张产品图、9 个变体、变体 SKU、价格和库存保持不变。

## 商品筛选

优先选择：

- 当前内容质量为“缺失内容”；
- 有在售版本，但销量、评价或曝光较低；
- 主图和描述足以核实商品外观、材质和版型；
- 没有明显的版权、商标或人物肖像风险；
- 尚未添加目标语言详情图。

遇到描述与图片矛盾、来源图带明显品牌/水印、材质不明确或商品状态异常时，先跳过并记录原因。

## 图片制作规则

- 参考图必须来自当前商品已有图片，先人工目检。
- 仅使用标题、描述或属性里明确出现的事实，例如 `Cotton`、`Crew Neck`、`Short Sleeve`。
- 保留原商品颜色、印花和版型，不替换成其他款式。
- 不添加价格、折扣、销量、品牌承诺、认证、尺寸表或未经证实的功能。
- 不添加商家 Logo、水印或促销语。
- 文案使用目标区域语言；首轮统一为英语。
- Joom 要求：PNG/JPG/JPEG，宽高比约 `0.6`，分辨率至少 550×550。
- 推荐成品尺寸：`1024×1707`。生成图比例不精确时用浅色留白补齐，避免拉伸商品：

  ```bash
  sips --padToHeightWidth 1707 1024 --padColor F8F5EF input.png --out output.png
  ```

## 推荐生成提示词结构

1. 说明这是 Joom 竖版电商详情图。
2. 要求忠实保留参考图中的商品、颜色、印花和版型。
3. 指定简洁背景与留白，不遮挡商品。
4. 只给 3–4 个已核实的英文卖点。
5. 明确禁止 Logo、水印、价格、折扣、尺码表和虚构卖点。
6. 明确输出宽高比约 0.6、至少 1024 像素宽。

## 后台操作

1. 打开 `/panel/products/<productId>/edit`。
2. 在“详情图”区域选择“添加详情图语言”。
3. 选择“英语”并添加。
4. 点击“添加图片”。注意：此按钮会先打开 Joom 的上传弹窗；需要再点击弹窗里的文件选择控件，浏览器才会出现文件选择器。
5. 上传本地成品图，等待预览完整出现。
6. 点击上传弹窗内的“保存”。此时应看到 `英语: 1/20`。
7. 在正式保存前核对标题、主图数量、变体数、价格、库存和 SKU 未变化。
8. 点击页面底部的全局“保存”。上传弹窗“保存”和页面全局“保存”是两个不同操作。
9. 保存后回到商品详情页，确认“详情图”语言显示为“英语”。

## 并行处理建议

- 每批并行打开 3–4 个编辑标签页，避免浏览器内存过高或上传状态串页。
- 每个标签页始终用商品 ID 和 SKU 双重识别。
- 图片上传可并行；每页保存后立即记录结果，不依赖标签页顺序。
- 一批全部保存后，再进入下一批。
- 2026-10-23 实测：3 个标签页可同时添加语言、触发文件选择和上传；单批的 Joom 云端处理约需 45–80 秒。
- 上传弹窗中“上传中”消失后，“保存”仍可能短暂处于禁用状态。可先确认图片 URL 已生成，再等待 10–20 秒，不要强制点击。

## 验收清单

- [ ] 详情图与当前商品一致，无错款或错色。
- [ ] 英文文字清晰、无拼写错误。
- [ ] 图片宽高比约 0.6，分辨率合规。
- [ ] 页面显示 `英语: 1/20`。
- [ ] 商品详情页显示“详情图 / 英语”。
- [ ] 标题、主图、类目、描述、属性未被意外修改。
- [ ] 变体数量和 SKU 未变化。
- [ ] 价格、库存和运费未变化。

## 已知注意事项

- 上传可能耗时 30–90 秒；预览未出现前不要重复点击。
- 商品详情页的内容质量等级可能异步更新；“详情图 / 英语”是保存成功的直接证据。
- 同一商品已存在英语详情图时不要重复创建语言。
- 正式保存生产商品前应由操作人确认本批次的商品清单和详情图。
